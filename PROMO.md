# Vibe Coding Tools — Submission & Backlink Kit

The site itself is built. What it lacks is **authority** (backlinks), which is the #1 factor for a new
domain to rank. This file is a copy-paste kit you can use to submit the site to directories, communities,
and launch platforms. Each section is ready to paste.

> Replace `https://vibe.david-cells.com` with your final custom domain if you set one up.
> All affiliate links on the site are currently placeholders (`https://example.com/aff/*`) — swap them
> for real Impact / partner URLs before promoting.

---

## 1. One-line description (reuse everywhere)
> **Vibe Coding Tools** — free, privacy-first, 100% client-side tools for AI-assisted developers: an AI
> cost calculator, LLM model compare, prompt generator, CLAUDE.md generator, project brief generator, and
> AI code-review + security checklists.

## 2. Elevator pitch (for directories / "what is this?")
Vibe Coding Tools is a collection of small, focused, browser-based utilities for people who build software
with AI. Nothing is uploaded — every tool runs in your browser. It covers the parts of the vibe-coding
workflow that actually cost time and money: estimating API spend before you build, comparing model prices
and context windows, writing better prompts and project briefs, and reviewing generated code for quality
and security.

## 3. Launch platforms
- **Product Hunt** — submit as a "tool / developer tool". Tagline: *"Estimate AI API cost, compare models,
  and review generated code — all in your browser."* First comment: link the AI Cost Calculator and Model
  Compare as the two flagship tools.
- **Hacker News (Show HN)** — title: *"Show HN: Privacy-first vibe-coding tools (cost calculator, model
  compare, prompt/CLAUDE.md generator)"*. Body: one paragraph on the client-side/no-upload principle + the
  problems each tool solves. Avoid marketing fluff; HN rewards substance.
- **BetaList / Indie Hackers** — post in the "launches" section with the elevator pitch above.

## 4. Communities (do NOT spam — one genuine post each, answer replies)
- **Reddit**
  - r/vibecoding — share the AI Cost Calculator + a tip about prompt caching.
  - r/ChatGPTCoding or r/LocalLLaMA — share the LLM Model Compare tool; ask for model corrections.
  - r/SideProject — standard launch post.
- **Discord / Slack** — many AI-dev Discords (e.g. local LLM, Cursor users) allow sharing useful free
  tools in a #showcase or #resources channel.
- **X / Twitter** — post the Model Compare + Cost Calculator with a screenshot; tag the relevant tool
  makers (they often retweet useful integrations).

## 5. Tool & resource directories (free listings = easy backlinks)
- **AlternativeTo** — list as alternative to "AI coding assistant" tools.
- **ToolDirectory / SaaSHub / Product Hunt alternatives** pages.
- **AI tool aggregators** — search "best AI coding tools directory" and submit; many accept free
  submissions.
- **GitHub** — push the repo (it is already Git-initialized) and add a README link; GitHub repos are
  indexed and pass some authority.

## 6. Internal linking already done (for crawler efficiency)
- Every model now has its own pricing page at `/models/<id>.html`, linked from the Model Compare tool.
- New blog posts (`is-vibe-coding-bad`, `how-to-vibe-code-a-website`, `best-ai-app-builder`) cross-link to
  tools.
- `sitemap.xml` and `robots.txt` are regenerated on every build and include all pages.

## 7. Suggested posting order (low effort → high effort)
1. Submit to 3–5 free directories (5 min each).
2. Post in 2–3 relevant subreddits / Discords (genuine, not spammy).
3. Product Hunt launch (one focused day).
4. Show HN post.
5. Periodic: when you add a tool or fix pricing, re-announce in the same threads.

> Rule of thumb: 5–10 quality backlinks from relevant sites move a new domain more than 10 more blog
> posts. Spend your first week on links, not content.
